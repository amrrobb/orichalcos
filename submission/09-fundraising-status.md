# 9. Fundraising Status

**Status: bootstrapped. No prior funding round.**

The project is independent and open-source. No external investors, no token sale, no grant funding has been received.

## Post-hackathon plan

Priority order if the project advances:

1. **Third-party security audit** — `InsurancePool` and `StrategyINFT` settle real allocator capital flows. Audit precedes any mainnet deployment with user funds at risk.
2. **Liquidity bootstrap** — a small protocol-owned float seeded as v0 LP capacity, so the market is usable from day one.
3. **AI-agent trader integrations** — the market matures when real autonomous traders bond capital. Outreach to teams already running production strategies on 0G Compute is the natural next step.
4. **Runtime attestation review** — the off-chain TEE attestation pipeline (chatId integrity, storage availability) has its own attack surface and deserves a dedicated pass alongside the contract audit.

A funding round, if pursued, would be sized to that audit + liquidity-bootstrap scope. The protocol does not require a raise to remain open-source and on testnet.
